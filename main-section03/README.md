# 쥬비랜드 (EN) main-section03 – From first step to future

5가지 솔루션 카드가 스크롤에 맞춰 01 → 05 순서로 올라오고, 화면 위쪽에 멈춰 다음 카드가 앞 카드를 완전히 덮으며 쌓이는 섹션입니다. 모션·카드 쌓기 코드(`main-section03.js`)는 한글판 `juviland/main-section03`과 같습니다.

- 피그마: en-main-section03(pc) `109:532` · en-main-section03(mob) `109:1107`
- 배포 주소: https://kimain1404-design.github.io/juviland-en/main-section03/

## 파일 구성

```
main-section03/
├─ index.html                           (주소로 바로 열리도록 이름 유지)
├─ main-section03.css                   반응형 레이아웃 + 등장 모션 + 카드 쌓기
├─ main-section03.js                    순서대로 등장 + 카드 쌓기 (iframe 대응, 한글판과 동일)
├─ main-section03-liveklass.html        라이브클래스에 붙여 넣을 iframe 코드
├─ README.md
└─ assets/
   ├─ main-section03(pc)-card1~5.webp   pc 일러스트 (한글판과 같은 그림, 글자 없음)
   └─ main-section03(mob)-card1~5.webp  mob·태블릿 일러스트
```

## 한글판과 다른 점

- PC 카드 높이 400 → 488px (영문 시안). 그림(700×400)은 카드 세로 가운데에 놓여 시안 위치와 같습니다.
- PC 태그: 2줄 고정 (2개 + 1개, 04는 1개 + 2개). 글꼴 폭이 달라도 줄 구성이 바뀌지 않도록 grid로 고정했습니다.
- 모바일 태그: 한 줄에 하나씩 3줄.
- 모바일 카드 높이: 설명 줄 수가 카드마다 달라 카드별로 다릅니다 (`main-section03.css`의 `--body-h`, 1080 시안 px 기준 894 / 766 / 919.6 / 830 / 894).
- 줄바꿈 고정: 제목·설명의 줄바꿈 위치를 시안대로 `<br>`로 고정하고 `nowrap`. PC와 모바일 위치가 다른 곳은 `<br class="pc-only">`, `<br class="mo-only">`로 나눴습니다. 문구를 바꾸면 줄바꿈 위치와 (모바일) `--body-h`도 함께 수정해야 합니다.

## 모션 (한글판과 동일)

- 등장: 섹션 제목 → 카드 01~05가 화면에 들어올 때 아래에서 올라옴. 그림이 한 박자 늦게 떠오름. 여러 장이 한꺼번에 보여도 0.14초 간격으로 01부터.
- 카드 쌓기: 카드가 화면 위쪽(PC 80px, 태블릿·모바일 56px)에 멈추고, 다음 카드가 같은 위치로 올라와 앞 카드를 덮음. 덮이는 카드는 살짝 작아지고 어두워짐. 멈추는 위치는 `--stack-top`으로 조절.
- 깃허브 페이지에서는 CSS `position: sticky`, 라이브클래스 iframe 안에서는 `main-section03.js`가 부모 화면 스크롤을 감지해 같은 움직임을 재현.
- "동작 줄이기" 설정 사용자는 모션 없이 바로 보입니다.

## 라이브클래스에 넣기

에디터 HTML(`<>`) 모드에 `main-section03-liveklass.html` 코드를 붙여 넣습니다. 높이 식이 계산하는 값:

- PC(1200px 이상): `184.5625vw`, 1600px 이상은 `2953px`
- 1199px 이하: `770.06vw`, `296.296vw + 3070px`, `5370px` 중 가장 작은 값 (모바일 → 태블릿 그림 커짐 → 그림 상한)
- 끝의 `+ 1px`은 바닥이 잘리지 않게 하는 여유분입니다.

320~2560px 32가지 폭에서 iframe 높이가 실제 섹션보다 0.8~1.2px 큰 것을 확인했습니다 (잘림 없음).
